# 📋 Complaint Management System

A web-based Complaint Management System developed using Flask and SQLite to efficiently manage customer complaints for a business. The system provides secure authentication, automated email notifications, and unique complaint tracking to improve customer service workflows.

## Overview

Managing customer complaints manually can be time-consuming and prone to errors. This application digitizes the entire complaint handling process by allowing complaints to be recorded, tracked, updated, and managed through a centralized web interface.

The project was built as a practical solution for a real business workflow, focusing on automation, organization, and improved customer communication.

---

## Features

- 🔐 Secure user authentication
- 📝 Register and manage customer complaints
- 🆔 Automatic complaint ID generation
- 📧 Automated email notifications
- 💾 SQLite database integration
- 📊 Complaint status tracking
- 🏢 Multiple dealership support
- 📱 Responsive web interface

## Project Workflow

1. User logs into the system.
2. Customer complaint details are entered.
3. A unique complaint ID is automatically generated.
4. Complaint information is stored in the SQLite database.
5. Automated email notifications are sent to the relevant recipients.
6. Complaint progress can be monitored and updated until resolution.
